# 本轮 UI 精修

本轮保留手机单屏结构与原有遥控、配对持久化和撤销行为，最初仅在本地验证；后续经用户授权纳入 v0.2.1 发布。

- 桌面默认 760×680 逻辑尺寸；根据当前显示器工作区缩小初始窗口。托盘恢复不重设窗口尺寸。旧版本没有持久化窗口尺寸记录，本轮没有新增或覆盖尺寸偏好。
- 等待配对突出二维码和配对码；已连接突出后台运行；已配对离线明确保留信任；停止后提供启动入口。
- 网卡和排障说明折叠；保持停止后才能换网卡。复制地址只在点击后执行并反馈结果。
- 配对码剩余有效期来自 Rust 的原有到期时间。HTTP 配对失败按实际错误/过期分类，仅调整展示，不改鉴权规则。后台运行仅隐藏当前本地窗口。
- 手机单输入框支持数字粘贴和前导零；有效六位才可提交，进行中阻止重复。圆形关闭按钮保留键盘焦点、遮罩关闭和草稿。
- 更多面板使用三加二排列、Esc 键帽；播放组合图标减小并增加间距，仍只发送快捷键。

窗口工作区和缩放处理参考 [Tauri Monitor API](https://docs.rs/tauri/2.11.5/tauri/window/struct.Monitor.html)，使用当前锁定依赖的接口。

## 验证命令

```powershell
npm run typecheck

npm run check:rust
npm run test:rust
npm run build
node scripts/verify-mobile-ui.mjs
node scripts/verify-ui-polish.mjs
```

`verify-ui-polish.mjs` 使用实际 Tauri WebView2 窗口和 Rust HTTP/WS，Chrome 模拟手机视口；测试前请退出已运行的枕控。脚本备份并恢复本应用配对设置与启动项，使用临时配对，不执行鼠标或键盘控制。截图和记录在 `output/playwright/ui-polish/`。结果 JSON 是本次运行证据，不随源码公开。

## 真机补验

1. Windows 显示设置分别选择 125%、150%，关闭并重新打开本地构建的 EXE；检查标题栏、底部操作可见，小屏可滚动访问设置。调整窗口后隐藏到托盘，再打开应保持本次尺寸。
2. 手机 Android / iPhone 浏览器打开配对面板；点击输入框应弹数字键盘，粘贴六位数字，确认输入与提交按钮不被键盘遮挡。自动聚焦不能唤起键盘时可点击输入框。
3. 点击后台运行，确认托盘仍在、手机仍可操作；通过真实托盘菜单恢复、停止和退出。这些手工菜单步骤不等同于自动化命令验证。
4. 手机断网再恢复，确认没有误报为凭证失效；主动撤销手机后才出现连接过期提示。确认输入草稿关闭后保留。

浏览器视口缩小不等于 Windows DPI 切换，也不等于真实手机软键盘。
