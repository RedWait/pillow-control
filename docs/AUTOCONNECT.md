# 自动连接与静默自启验收

2026-09-15：实现持久信任、登录后静默自启、可取消设置、网络未就绪重试。保存位置为当前用户 `%LOCALAPPDATA%/org.pillowcontrol.desktop/preferences.json`。只保存令牌摘要和启动/网卡设置，不保存明文控制令牌。设置加载失败时拒绝启动，避免误用损坏凭证。

首次配对会默认开启自启；用户明确关闭后不会因再次配对自动打开。配对更新替换旧手机，撤销在重启后继续有效。停止遥控、退出程序保留配对；开机自启仍按设置生效。Windows 启动管理、安全软件、系统网络及防火墙可能阻止自启或连接，查看桌面设置和系统启动应用。

实现参考 [Tauri 官方 Autostart](https://v2.tauri.app/plugin/autostart/)。只允许本地桌面页面调用开关；Windows 当前用户 Run 项名称 pillow-control，程序路径带引号，参数 --autostart；窗口从创建时隐藏，手动启动再显示，自动启动不抢焦点。安装版卸载清理本应用启动项；便携版删除前请先关闭自启。

## 验证范围

- Rust 自动测试：磁盘重新加载后信任保留、撤销持久化、不存明文令牌、损坏数据拒绝、保存失败不授予凭证、显式关闭自启不被再次配对覆盖、HTTP/WS 重启后认证。
- 浏览器/Windows 脚本：`node scripts/verify-autoconnect.mjs`，实际注册表、自启参数启动、窗口可见性、原浏览器重新连接、撤销及关闭自启（结果见 artifacts/autoconnect-results.json）。测试前备份本应用设置与启动项，使用临时配对，结束恢复原内容。
- 人工补验：安装新版并配对，勾选开机自启后重启 Windows、登录，确认无主窗口闪现且托盘可打开；原手机浏览器访问原网址自动连接。关闭自启再重启确认不启动。真实 Windows 开机/登录和手机 Wi-Fi 需用户完成，自动启动参数测试不等同于重启验收。
