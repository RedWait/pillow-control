# 枕控 PillowControl 0.2.0 真机验收清单（约 10 分钟）

记录：日期 / Windows 版本 / 安装或便携版 / 手机型号与浏览器 / Wi-Fi 与网线拓扑。

- [ ] 安装包：普通用户运行安装向导，安装到用户目录，桌面标题显示「枕控 PillowControl」。无需 Node/Python/Rust/编译工具；无 WebView2 时离线安装运行时。
- [ ] 便携版：解压 ZIP，在已有 WebView2 的机器双击 pillow-control.exe 启动；托盘恢复、停止遥控、明确退出都有效。退出后手机不能再操作。
- [ ] 配对：扫描选定的实体网卡地址；输错一次不能连接，正确后连接。二维码不包含配对码。
- [ ] 多网卡：有 VPN / 虚拟网卡时，默认选实体网卡；停止后换地址，旧地址不再监听。
- [ ] 鼠标：单指滑动是相对移动；点按单击、双击打开测试文件、左键、右键菜单正常；滑动结束不误点击。
- [ ] 手势：双指上下滚动，抬起一指不跳鼠标、不产生点击；备用滚动上下方向正确。调整灵敏度效果可感知。
- [ ] 音量：加减改变 Windows 系统音量，静音/恢复有效；无音频设备时显示失败信息。
- [ ] 窗口：打开至少三个普通窗口，连续切换到第三个，确认进入；反向选择有效；取消返回；等待 3 秒自动释放 Alt。
- [ ] 显示桌面：返回桌面，再点一次按 Windows 原有逻辑恢复。
- [ ] 中文：记事本获得焦点，手机输入法组词期间发送不可用，选字完成后发送「枕控中文 ABC 123 😀」，不重复、不遗漏。测试多行、标点及英文。
- [ ] 剪贴板：提前复制测试内容，发送文字后粘贴，仍为原内容。
- [ ] 快捷键：在记事本试空格、方向键、回车、Esc；播放器中另测快捷键，记录播放器和焦点依赖。
- [ ] 断网：切换窗口过程中关手机 Wi-Fi，Alt 自动释放；恢复后能重连，旧点击/按键/文字不重放。
- [ ] 隐藏页面：切其他 App、锁手机屏幕，按键释放；返回后自动重连。
- [ ] 凭证撤销：电脑点击「断开并撤销手机」或「重新配对」，旧页面不能继续控制，必须输入新码。
- [ ] 布局：Android Chrome、iPhone Safari 竖横屏、软键盘、刘海/底部安全区正常；触控板手势不触发页面缩放或滚动。
- [ ] 权限边界：普通窗口能操作；UAC、锁屏或管理员窗口不作为首版通过条件；程序始终普通用户运行。

请分别记录通过、失败和未测。构建或桌面浏览器自动化通过不能替代这些实体手机结果。

- [ ] 卸载：从 Windows 已安装应用卸载，确认进程退出和端口释放；先保存任何测试记录。
