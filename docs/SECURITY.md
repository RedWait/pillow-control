# 安全设计与边界

本程序授权后可以控制电脑，请仅在可信家庭 LAN 使用。

## 入口

- `/` 和 Vite 构建资源是公开静态页面；页面本身不具备系统权限。
- `POST /api/pair` 是唯一无需令牌的写接口，需要同源 Origin、精确 Host、JSON 和有效配对码。
- `GET /api/status` 需要同源 Origin 及 `Authorization: Bearer <token>`；没有 HTTP 控制接口。
- `/ws` 升级校验同源 Origin 和 Host。升级后必须在 3 秒内用第一条 `{kind:'auth', token}` 消息认证；认证前不执行控制指令。令牌不放 URL 或二维码。
- 每个命令包含单调递增 id。未知类型、额外属性、超范围、二进制、过大和超频消息关闭连接。认证后也不能调用内部探测方法。

## 生命周期与限额

随机配对码使用 `crypto.randomInt`，有效 10 分钟。每 IP 每分钟最多 6 次配对，整个服务每分钟最多 30 次。限速表过期回收并有最大条目数，不按 X-Forwarded-For 信任客户端。随机令牌为 32 字节，服务端保留 SHA-256 摘要并用常量时间比较。重新配对、停止、退出或再次成功配对撤销旧令牌。

最大 HTTP 连接数 32，WS 握手候选连接 8，每 IP 每分钟 30 次升级；HTTP 请求体最多 2048 字节，WS 最多 8192 字节。每连接 100 消息/秒，文字每 10 秒 4 条，单次文字不超过 1000 UTF-16 单元。底层辅助程序最多 32 个待确认请求。

移动操作在手机 33ms 合并，服务器串行队列最多 16 项并合并相邻移动，发生背压时丢弃新操作。断线清空尚未执行的操作，优先释放按键。手机不维护离线操作队列，重连不重放；模糊结果提示用户检查电脑。

页面隐藏 / pagehide / pointercancel 清空手势状态并释放。WS 关闭、停止、替换连接执行 release；应用心跳超时约 3.5–4 秒断开。辅助程序内部独立的 3 秒无操作看门狗释放持有的 Alt，主进程崩溃导致 stdin EOF 也释放。常规键和点击按下/松开成对插入，失败时尽力补发松开事件。已插入 Windows 输入队列的事件无法撤回。

## 不提供的保护

HTTP/WS 没有 TLS：同网攻击者可能监听、篡改网页或盗取令牌。配对、CSP 和来源校验不能解决中间人攻击。不得把本程序暴露到公网；不要向未知设备透露配对码或共享手机浏览器存储。

浏览器本地存储可能被清理，此时需要重新配对。电脑端重启后凭证丢失是有意设计。设备 IP 改变导致浏览器 origin 改变，也需要重新配对。

不自动修改防火墙或路由器，不提供公网映射、任意 shell、脚本、文件 API，也不监听辅助程序网络端口。锁屏、安全桌面与管理员窗口受 Windows 权限隔离限制；默认保持普通用户权限。
