# 安全设计与边界

本程序授权后可以控制电脑，请仅在可信家庭 LAN 使用。

## 入口

- `/` 和 Vite 构建资源是公开静态页面；页面本身不具备系统权限。
- `POST /api/pair` 是唯一无需令牌的写接口，需要同源 Origin、精确 Host、JSON 和有效配对码。
- `GET /api/status` 需要同源 Origin 及 `Authorization: Bearer <token>`；没有 HTTP 控制接口。
- `/ws` 升级校验同源 Origin 和 Host。升级后必须在 3 秒内用第一条 `{kind:'auth', token}` 消息认证；认证前不执行控制指令。令牌不放 URL 或二维码。
- 每个命令包含单调递增 id。未知类型、额外属性、超范围、二进制、过大和超频消息关闭连接。认证后也不能调用内部探测方法。

## 生命周期与限额

随机配对码使用 Rust `getrandom` 调用操作系统安全随机源（拒绝采样避免取模偏差），有效 10 分钟。每 IP 每分钟最多 6 次配对，整个服务每分钟最多 30 次。限速表过期回收并有最大条目数，不按 X-Forwarded-For 信任客户端。随机令牌为 32 字节，服务端保留 SHA-256 摘要并用常量时间比较。主动撤销、重新配对或再次成功配对撤销旧令牌；停止、退出、重启保留信任。

最大 HTTP 连接数 32，WS 握手候选连接 8，每 IP 每分钟 30 次升级；HTTP 请求体最多 2048 字节，WS 最多 8192 字节。每连接 100 消息/秒，文字每 10 秒 4 条，单次文字不超过 1000 UTF-16 单元。每连接最多 32 个待确认请求。

移动操作在手机 16ms 合并（约 60 次/秒），服务器串行队列最多 16 项并合并相邻移动，发生背压时丢弃新操作。断线清空尚未执行的操作，优先释放按键。手机不维护离线操作队列，重连不重放；模糊结果提示用户检查电脑。

页面隐藏 / pagehide / pointercancel 清空手势状态并释放。WS 关闭、停止、替换连接执行 release；应用心跳超时约 3.5–4 秒断开。Rust 控制线程的 3 秒无操作看门狗释放持有的 Alt，正常退出会关闭服务并等待控制线程释放。常规键和点击按下/松开成对插入，失败时尽力补发松开事件。已插入 Windows 输入队列的事件无法撤回。

## 不提供的保护

HTTP/WS 没有 TLS：同网攻击者可能监听、篡改网页或盗取令牌。配对、CSP 和来源校验不能解决中间人攻击。不得把本程序暴露到公网；不要向未知设备透露配对码或共享手机浏览器存储。

浏览器本地存储可能被清理，此时需要重新配对。电脑端重启后从本地加载令牌摘要，继续验证已有凭证。设备 IP 改变导致浏览器 origin 改变，也需要重新配对。

不自动修改防火墙或路由器，不提供公网映射、任意 shell、脚本、文件 API，不捆绑 Node 服务或系统控制辅助程序。锁屏、安全桌面与管理员窗口受 Windows 权限隔离限制；默认保持普通用户权限。


## Tauri 权限与打包

只有本地 main 窗口可调用 desktop_state 和 desktop_action。build.rs 显式登记命令清单，capabilities 仅授予这两个权限；commands 额外检查窗口标签及本地页面 URL。没有通用 shell、文件或远程来源授权，手机网页不含 Tauri API。HTTP 静态资源通过 include_dir 编译嵌入，不能读取任意磁盘文件。运行无 Node、Python 或 C# 控制进程。

开发验证模式 --verify-server 只从本地标准输入接收诊断，HTTP/WS 白名单不允许 probe 或恢复音量等内部动作。桌面验收脚本的 WebView2 调试端口仅通过该测试子进程环境变量启用，不是正常运行配置。

被任务管理器强制终止、操作系统崩溃或控制线程永久卡死时，进程内清理无法保证执行；如果强杀发生在保持 Alt 期间，手动按下再松开 Alt。断线、页面隐藏、正常停止/退出和空闲看门狗的释放属于已实现保障，不能等同于崩溃保障。
