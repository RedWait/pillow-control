# 鼠标定位光环（未发布的本地开发版）

光环用于远距离找鼠标，放大镜仍是可选的局部阅读辅助。光环默认开启：电脑端展开 **遥控设置**，可关闭或选择小 / 中 / 大（64 / 88 / 112 逻辑像素直径）。设置保存在现有 `preferences.json` 中，旧设置没有该字段时采用开启、中等，不改已有配对、自启、网卡选择。

手机的非零鼠标移动指令成功调用 `SendInput` 后，只更新一次唤醒时间。电脑读取实际系统光标位置显示圆环，持续遥控时保持显示；停止遥控移动 1 秒后，在 250 ms 内淡出。本地鼠标移动不会唤起或延长光环。刚停止遥控、光环仍可见时，圆环仍跟随实际指针，避免位置误导。

圆心完全透明，亮色主描边两侧有暗色描边。覆盖层使用 `WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_TOPMOST`，不抢焦点、不处理点击、不进任务栏 / Alt+Tab。未更改 Windows 鼠标主题或指针大小，也没有新增网络控制指令。

## 实现

- `src-tauri/src/pointer_halo.rs`：独立线程、最新移动时间合并、最多 40 fps；每个可见会话复用一个窗口和缓存位图，不在鼠标输入线程绘制，不按移动消息创建窗口。淡出后停止动画；断开连接 / 停止服务会唤醒线程，直接销毁覆盖层与 GDI 资源，退出会回收线程。
- 按监视器 DPI 生成小位图，切换大小或 DPI 时才重建。绘制线程启用 Per-Monitor V2，使用 `GetPhysicalCursorPos`，直接以带符号屏幕坐标定位，不累计手机位移。圆环中心固定在光标；屏幕边缘允许超出屏幕的部分自然裁切，不把圆环错误挪离指针。
- 设置更新仍经过受限桌面 command 和 Rust Service；保存失败显示原有错误反馈。绘图异常在电脑端状态中报告，不阻断已有鼠标 / 键盘控制。
- 功能覆盖普通桌面合成窗口，不承诺覆盖独占全屏、UAC 安全桌面、锁屏、受保护视频内容或更高权限窗口；不要求管理员权限。第三方播放器的置顶窗口策略可能影响覆盖顺序。

官方依据：[分层窗口的透明命中测试](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)、[UpdateLayeredWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-updatelayeredwindow)、[物理光标坐标](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getphysicalcursorpos)。

本轮实际结果：

- 类型检查、55 项前端测试、22 项 Rust 测试、生产 EXE 构建通过。
- 本机 Windows 已验证实际光标跟随、透明圆心和描边命中穿透、真实点击、不抢焦点、停止后的淡出、本地移动不唤起、尺寸切换、关闭开关销毁、断线销毁、屏幕左上角裁切。普通、最大化、无边框**测试窗口**显示通过；没有把测试窗口当作真实播放器验收。
- 实际双屏：主屏 1920×1080 / 96 DPI（100%）；左侧屏幕起点 `(-2880, 107)`、2880×1800 / 192 DPI（200%）。中档在两屏上分别为 88 / 176 物理像素，原生窗口中心与系统光标坐标一致。
- 实际 Tauri WebView2 验证开关及大小保存、重启恢复，配对、自启选择、托盘隐藏和服务停止行为保持正常。对应截图 `output/playwright/ui-polish/desktop-halo-settings.png`；实际光环截图 `artifacts/pointer-halo.png`，原生验证明细 `artifacts/tauri-windows-verification.json`。
- 验证脚本修正了原有测试夹具对焦点和 UI Automation 的假设：输入前实际激活自有测试窗口，只读取记事本的可见编辑区域；连续 Alt+Tab 在 Windows 切换器打开后再选择。没有为测试更改产品窗口切换逻辑。
- 没有改动系统显示配置；125% / 150% 只有几何单元测试，仍需实际缩放验证。没有发布新安装包或推送代码。
