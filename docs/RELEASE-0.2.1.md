# 枕控 PillowControl v0.2.1

本版让电脑端更像紧凑的配对工具，并精修手机控件；保留 v0.2.0 的持久配对、静默自启、控制白名单与断线释放行为。

- 电脑默认 760×680 逻辑尺寸，按显示器工作区适配；扫码/配对码优先，已连接、离线、停止状态清晰，设置与排障可折叠。
- 复制地址、后台运行入口；后台运行仅隐藏窗口，停止与撤销语义明确。
- 手机单屏结构不变；六位数字配对输入、重复请求保护、准确的错误/过期/网络提示；圆形关闭按钮、Esc 键帽与三加二的更多操作分组。
- 重写中英文 README，加入真实页面渲染的演示截图、下载指引、贡献指南和独立开发/排障文档。

## 下载

- `pillow-control-0.2.1-setup-x64.exe`：推荐，Windows x64 当前用户安装，包含 WebView2 离线安装程序。
- `pillow-control-0.2.1-portable-x64.zip`：解压运行，需要已有 WebView2。
- `pillow-control-0.2.1-SHA256SUMS.txt`：下载校验。

更新前从托盘退出旧版。更新后刷新手机网页；同一 Windows 用户、浏览器和地址的既有配对保留。便携版开启自启时应保持程序路径不变。

## 验证范围

类型检查、44 项前端测试、16 项 Rust 测试及生产构建通过。手机 15 组浏览器视口回归通过；实际 Tauri/Rust 服务的配对、连接状态、后台隐藏保持连接、停止保留信任检查通过。

本轮聚焦 UI 和文档，没有重跑所有 Windows 鼠标、音量、记事本输入测试。手机真实软键盘/触摸、Wi-Fi、Windows 125%/150% 实际缩放、完整重启登录自启与全新系统安装仍需真机验收。README 截图使用演示数据，不冒充真机连接证据。

HTTP/WS 未加密，仅适用可信家庭局域网。程序未签名；不支持 UAC、锁屏、管理员权限窗口。播放器按钮发送当前窗口快捷键，没有播放状态回传。
