# 遥控操作增强（本地开发版，尚未发布）

## 使用

- **更多**固定两行：Esc / 显示桌面 / 删除；向上滚动 / 向下滚动 / 回车。删除发送 **Backspace**，作用于当前焦点，不是 Delete 键。面板外轻点关闭；从面板内拖到外部不会误关闭。
- 双指上下滑动滚动。滚动增量累计到完整 Windows 滚轮刻度再发送，抬起一指后不转为鼠标移动或误点击。备用上下滚动保留，便于单手点按，也能作为浏览器手势异常时的替代操作。电脑上的鼠标应位于可滚动区域。
- **设置 → 开启鼠标放大镜**：电脑显示跟随鼠标的 2 倍局部放大镜，停下约 1.4 秒隐藏，移动后再次显示。浮窗不抢焦点、不拦截点击，不传输屏幕。断线、切后台断开会话、停止服务及退出后关闭；重新连接需要再次开启。
- **设置 → 关闭电脑… → 确认关机**：向 Windows 请求正常关闭应用并关机，包括枕控。不是强制结束所有进程；未保存文件可阻止关机，Windows 中取消后枕控继续运行。请求后需查看电脑，手机不宣称关机完成、不自动重试。若取消后要再次关机，刷新手机页面后重新确认。

## 实现与边界

保持现有配对、持久凭证、单活动连接、来源校验、限速和消息大小限制。仅新增 `key: backspace`、`magnifier: {enabled: boolean}`、`shutdown: {confirmed: true}` 白名单指令，无任意命令行或文件接口。

`confirmed` 是显式指令参数，不是第二重身份验证；任何已配对、获准控制电脑的客户端都具有关机能力。只在可信局域网使用，HTTP/WS 仍未加密。

Windows 放大镜采用系统 Magnification API 的窗口控件，不使用需要 UIAccess 的全屏变换，不安装辅助进程。关机临时启用当前用户已有的关机权限，随后恢复，不请求管理员提升。调用 `ExitWindowsEx(EWX_POWEROFF)`，不使用 `EWX_FORCE` 或 `EWX_FORCEIFHUNG`；不提前退出枕控。

官方依据：[滚轮刻度](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)、[放大镜控件](https://learn.microsoft.com/en-us/windows/win32/winauto/magapi/magapi-intro)、[正常关机与未保存应用](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-exitwindowsex)。


浏览器 UI 测试使用明确模拟的 WebSocket，包括关机确认和重复提交阻止，**不会真实关机**。Windows 验证脚本使用独立测试窗口和新建记事本文档，测试真实系统输入与放大镜生命周期，**不会调用关机**。本轮未打包安装程序、未推送或发布。

## 待真机验收

1. 手机连接本地新 EXE（先从托盘退出旧版本）。打开更多，核对六键位置；在测试文本末尾点击删除，应向前删除一个字符。点击面板外关闭，电脑鼠标不应误点击。
2. 电脑打开长网页，将鼠标停在内容区；手机双指同向滑动，检查两个方向。抬起一指继续移动不应变成鼠标移动；重新落下第二指应继续滚动。另测单指点按、双击，避免退化。Android/iPhone 各测一次。
3. 设置开启放大镜，在不同显示器和 125%/150% 缩放下移动，核对指针位置、放大内容、屏幕边缘、不抢焦点和点击穿透。静止隐藏，再移动显示。手机切后台、断网、电脑停止服务后应消失。
4. **关机仅在方便结束工作的时段手动验收**：先保存重要文件；可另开一份临时未保存文档。手机确认关机后检查 Windows 保存提示，取消后遥控仍可使用；保存后再次确认，检查 Windows 正常退出应用并关机。某些应用会自动保存，不保证都弹出阻止提示。
5. 测试真实手机软键盘和较小屏幕的设置/关机面板滚动；浏览器视口模拟不代替手机真机验证。
