# 枕控 PillowControl v0.2.0

Windows x64 局域网遥控工具，手机浏览器直接使用，无需手机 App。

## 本版功能

- Tauri 2 + Rust 桌面程序与局域网服务，内嵌 Vue 手机页面，不依赖 Node.js 或开发服务器。
- 单屏夜间遥控界面，触控板、音量、播放快捷键同屏；键盘、窗口切换、更多操作按需展开。
- 鼠标移动发送周期调整为 16ms，启用 TCP_NODELAY；保留消息合并、限速与断线释放。
- 首次配对后保存信任，电脑程序重启后原手机浏览器可自动连接；支持撤销凭证。
- 首次配对默认启用登录后静默启动，可在桌面设置关闭；用户明确关闭后不会被再次配对覆盖。
- 更新品牌 Logo，为安装对话框提供高对比度图标。

## 下载与使用

- `pillow-control-0.2.0-setup-x64.exe`：安装版，包含 WebView2 离线运行时。
- `pillow-control-0.2.0-portable-x64.zip`：便携版，需系统已有 WebView2。开启自启后请勿移动程序位置。
- `pillow-control-0.2.0-SHA256SUMS.txt`：SHA-256 校验值。

启动电脑程序，手机连接同一局域网，扫码并输入配对码。之后请使用同一浏览器和网址；浏览器数据清理、地址变化或主动撤销后可能需要重新配对。

## 验证与限制

本次发布前通过前端类型检查、42 项前端测试和 16 项 Rust 测试。此前已完成真实 Windows 鼠标、中文输入、音量、连续窗口切换及打包程序验证；自动连接的 12 项检查覆盖实际注册表、程序重启和浏览器重连。安装图标已在实际语言选择对话框检查。

手机界面验证使用桌面 Chromium 手机视口，不能代替 Android/iPhone 真机触摸、软键盘及 Wi-Fi 验收。真实 Windows 重启登录后的自启、全新 Windows/WebView2 安装和卸载仍需人工确认。详见仓库 docs 中的验证记录与验收清单。

仅适用于可信局域网，HTTP/WS 不加密，不配置公网暴露。程序未签名；不支持 UAC 安全桌面、锁屏或管理员权限窗口。播放器按钮发送当前窗口快捷键，不代表播放器状态反馈。
